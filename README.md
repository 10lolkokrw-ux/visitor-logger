# Visitor Logger

Небольшой Flask-проект с закрытой админ-панелью. Посетитель сам подтверждает согласие на запись IP, User-Agent и времени посещения. Нет геолокации, скрытого fingerprinting или сканирования портов.

## Публикация через Render

1. Создайте GitHub-репозиторий и загрузите туда все файлы проекта.
2. На Render выберите **New → Blueprint**, подключите репозиторий и подтвердите создание сервиса по `render.yaml`.
3. В настройках Environment задайте `ADMIN_PASSWORD` — длинный уникальный пароль. Не используйте пароль от других аккаунтов.
4. После деплоя откройте адрес сайта. Админка: `https://ВАШ-ДОМЕН/admin/login`.

`render.yaml` подключает постоянный диск для SQLite. На бесплатных тарифах условия постоянных дисков/сервисов могут меняться; проверьте актуальные условия Render перед публикацией.

## Локальный запуск (Windows)

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
$env:SECRET_KEY = "replace-with-a-long-random-secret"
$env:ADMIN_PASSWORD = "set-a-unique-long-password"
$env:COOKIE_SECURE = "0"
py app.py
```

Откройте `http://127.0.0.1:5000`. Админка — `/admin/login`.

## Важно

- Сбор начинается только после явного согласия на странице.
- Укажите в собственной политике конфиденциальности, кто собирает данные, зачем, срок хранения и способ связаться с владельцем сайта.
- Удаление старых записей выполняется при старте приложения и открытии админки; срок хранения по умолчанию — 7 дней.
- IP может быть адресом VPN, прокси или общего NAT, а не конкретного человека.
- Сервер видит порт своего веб-соединения; клиентский исходящий порт обычно не доступен приложению.
- Не публикуйте IP-журнал и защищайте пароль админки.
